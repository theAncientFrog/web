```bash

psql $DATABASE_URL -f prisma/migrations/20251209211215_add_restaurant_i18n_fields/migration.sql
```

Або скопіюйте SQL з файлу і виконайте в pgAdmin / Supabase SQL Editor.

## Перевірка:

Після виконання команди `migrate resolve`, перевірте:

```bash
npx prisma migrate status
```

Має показати, що всі міграції застосовані.
